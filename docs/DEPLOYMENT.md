# SafeStop 360 — Production Deployment Guide

SafeStop 360 uses environment-driven configuration so the React frontend can deploy to **Vercel** or **Netlify**, while the Django REST API and Managed PostgreSQL database deploy to **Render** (or any compatible Python WSGI host).

---

## 1. Backend + Managed PostgreSQL (Render)

1. Push the repository to GitHub (confirming `.env` and `db.sqlite3` are excluded).
2. In Render, choose **New → Blueprint** and connect your repository — Render automatically reads [render.yaml](../render.yaml).
3. Configure the production environment variables on `safestop360-api`:
   - `DJANGO_DEBUG=False`
   - `DJANGO_SECRET_KEY=<strong-random-key>` (auto-generated by Render)
   - `DATABASE_URL=<managed-postgres-connection-string>` (wired automatically by `render.yaml`)
   - `DJANGO_ALLOWED_HOSTS=<your-render-domain>.onrender.com`
   - `CORS_ALLOWED_ORIGINS=https://<your-frontend-domain>`
   - `CSRF_TRUSTED_ORIGINS=https://<your-frontend-domain>,https://<your-render-domain>.onrender.com`
4. Render executes `backend/build.sh`:
   - Installs dependencies from `backend/requirements.txt`
   - Runs `python manage.py collectstatic --noinput` (served via WhiteNoise)
   - Runs `python manage.py migrate --noinput`
5. Start command:
   ```bash
   gunicorn safestop.wsgi:application --bind 0.0.0.0:$PORT --workers 2 --timeout 60
   ```
6. Verify live backend health:
   ```bash
   curl https://<your-render-domain>.onrender.com/api/health/
   ```
   Confirm `"status": "ok"` and `"database": { "connected": true, "vendor": "postgresql" }`.
7. *(Optional for ideathon demo only)* Seed clearly labelled `[DEMO]` Bengaluru data via Render Shell:
   ```bash
   python manage.py seed_demo_data
   ```

## 2. Frontend (Vercel or Netlify)

### Vercel
1. Import the GitHub repository in Vercel.
2. Set **Root Directory** to `frontend`.
3. Build command: `npm run build` · Output directory: `dist`.
4. Add Environment Variable:
   - `VITE_API_BASE_URL=https://<your-render-domain>.onrender.com/api`
   - `VITE_APP_ENV=production`
5. `frontend/vercel.json` handles React Router SPA rewrites and security headers automatically.

### Netlify
1. Import the GitHub repository in Netlify.
2. Set **Base directory** to `frontend`, **Build command** to `npm run build`, and **Publish directory** to `frontend/dist`.
3. Add `VITE_API_BASE_URL=https://<your-render-domain>.onrender.com/api`.
4. `frontend/public/_redirects` handles React Router SPA fallback automatically.

## 3. Post-Deployment Verification Checklist
- [ ] `GET /api/health/` returns HTTP `200` with PostgreSQL connected.
- [ ] Registering a new Woman user works and issues JWT tokens.
- [ ] CORS allows requests from the deployed frontend domain and blocks unknown origins.
- [ ] Approved SafePlaces load on the Leaflet map without mixed-content errors.
- [ ] Partner registration stays `PENDING` until approved in `/admin/partners`.
- [ ] Assistance Confirmation Loop transitions work end-to-end (`PENDING → ACCEPTED → ARRIVED → CLOSED`).
- [ ] India official emergency numbers (`112` and `181`) are clearly visible and clickable.
